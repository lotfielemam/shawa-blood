# دليل فصائل دم قرية شاوة
**Shawa Village Blood Type Directory**

﴿وَمَنْ أَحْيَاهَا فَكَأَنَّمَا أَحْيَا النَّاسَ جَمِيعًا﴾ — قطرة دم منك… حياة لغيرك

الرابط: https://lotfielemam.github.io/shawa-blood/

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة كاملة (التصميم والبرمجة والبيانات بداخلها) وتعمل أيضًا دون جافاسكربت في معاينات الملفات |
| `manifest.webmanifest` | بيانات التطبيق للتثبيت على الشاشة الرئيسية (PWA) |
| `service-worker.js` | التشغيل دون إنترنت؛ الصفحة تُجلب من الشبكة أولًا حتى لا تُعرض بيانات قديمة وأنت متصل |
| `offline.html` | صفحة بديلة عند انقطاع الإنترنت قبل أول زيارة |
| `icons/` | الشعار وأيقونات التطبيق (192، 512، Maskable، Apple) |
| `assets/og-image.png` | صورة معاينة الرابط في واتساب وفيسبوك (1200×630) |

## التحديث
1. افتح **نسخة المراجعة الخاصة** على جهازك (لا تُرفع للإنترنت)، وادخل برمز الأدمن.
2. أكّد الأسماء، ثم «تنزيل صفحة النشر index.html».
3. استبدل `index.html` هنا بالملف الجديد.
4. عند تغيير أي ملف آخر ارفع رقم `VERSION` في `service-worker.js` حتى تصل التحديثات للأجهزة المثبَّت عليها الدليل.
